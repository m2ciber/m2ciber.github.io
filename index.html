Analizador de phishing con IA local

  • Python
  • Ollama
  • Expresiones regulares

Analiza correos .eml en dos capas: comprobaciones automáticas verificables con código (remitente, SPF, DKIM, enlaces con IP, lenguaje de urgencia) y un informe redactado por un modelo local. Documenta los fallos del modelo y por qué su informe debe revisarlo una persona.

Detector de intrusiones de red con Machine Learning

  • Python
  • pandas
  • scikit-learn
  • NSL-KDD

Random Forest evaluado con el dataset real NSL-KDD: 78 % de acierto en la prueba oficial, 2,7 % de falsas alarmas y un 37 % de ataques sin detectar. El README recoge los resultados, sus límites y los siguientes pasos.

Laboratorio de prompt injection y defensa

  • Python
  • Ollama
  • Registro de auditoría

Ataques de prompt injection (OWASP LLM01) y fuga de información (LLM06) contra un asistente local, con un firewall de entrada y otro de salida. Con dos modelos comparados: uno resiste y el más pequeño entrega las credenciales ficticias cuando no hay protección.
